Protokol Segmentasi — Materi "Pemrograman Java"

Perbandingan dua model segmentasi pada Kit-Build Concept Map · Goal map 12 konsep / 12 proposisi · Materi baca 4 paragraf

Prinsip Umum

Goal map, materi bacaan, kit, serta instrumen (Pre-Test, Post-Test, Kuesioner) identik untuk kedua kelompok. Satu-satunya perbedaan adalah pengelompokan konsep ke dalam segmen, yang divisualisasikan melalui warna konsep pada goal map. Segmentasi ditentukan manual oleh peneliti mengikuti protokol di bawah, bukan dihitung otomatis oleh sistem.

A Model 1 — Segmen Paragraf (Kelompok Java 1)

Aturan: satu segmen = satu paragraf materi bacaan. Konsep yang dibahas pada paragraf ke-n diberi warna ke-n. Urutan rebuild siswa mengikuti alur bacaan.

Segmen Sumber Konsep (node) Jumlah
Segmen 1 Paragraf 1 — Pengertian Java & JVM Java, JVM 2
Segmen 2 Paragraf 2 — Kompilasi & eksekusi Source code, Compiler, Bytecode 3
Segmen 3 Paragraf 3 — Struktur program & OOP Class, Main method, Method, Objek 4
Segmen 4 Paragraf 4 — Variabel, tipe data, library, output Variabel, Tipe data, Library, Output 4

B Model 2 — Segmen Depth-Topic (Kelompok Java 2)

Aturan: satu segmen = satu level kedalaman pada hierarki goal map, dari konsep paling umum (level 0–1) ke paling spesifik (level 4). Level dihitung dari jarak node ke akar hierarki ("Java"). Warna segmen memakai palet yang sama agar variabel warna terkendali.

Segmen Level kedalaman Konsep (node) Jumlah
Segmen 1 Level 0–1 — konsep inti (akar hierarki) Java, JVM, Bytecode, Class, Variabel 5
Segmen 2 Level 2 — konsep menengah Source code, Compiler, Method, Objek, Tipe data 5
Segmen 3 Level 3 — konsep rincian Main method, Output 2
Segmen 4 Level 4 — paling spesifik Library 1

Contoh Pemetaan yang Berbeda

Konsep yang sama mendapat warna berbeda di tiap model — inilah treatment yang dibandingkan:

Konsep Model Paragraf Model Depth-Topic
Bytecode Paragraf 2 (dibahas saat kompilasi) Level 0–1 (konsep inti)
Class Paragraf 3 (dibahas saat struktur program) Level 0–1 (konsep inti)
Main method Paragraf 3 Level 3 (rincian)
Library Paragraf 4 Level 4 (paling spesifik)

Langkah Penerapan di Sistem

  • Goal map dibuat satu kali di editor (12 konsep, 12 proposisi), tanpa warna segmen.
  • Setiap konsep diberi warna di editor goal map sesuai tabel di atas — manual, oleh peneliti.
  • Kit dipecah otomatis oleh sistem berdasarkan warna; siswa merebuild per segmen sesuai urutan warna.
  • Map Score, waktu pengerjaan, dan analytics dihitung otomatis dan identik untuk kedua kelompok.
  • Keputusan pemetaan tiap konsep (kenapa X masuk segmen Y) didokumentasikan di tabel ini dan dilampirkan pada Bab Metodologi.
